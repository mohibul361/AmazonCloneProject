## Overview

This project is a simple **Amazon Demo** website that replicates the basic functionality and design of Amazon's homepage. It allows users to interact with various sections, such as navigation, search, product categories, and more. The design focuses on user-friendliness and responsiveness.

## Features

- **Navigation Bar**: Users can access various sections like account, orders, cart, and search.
- **Search Bar**: Allows users to search for products.
- **Product Categories**: Displays different categories such as clothes, electronics, health, and personal care.
- **Hero Section**: Promotional message for shopping in a specific country.
- **Shop Section**: Various product categories, each with an image and "See More" link.
- **Footer**: Includes links to Amazon services, help, and policies.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling the components and layout.
- **Font Awesome**: For icons used in navigation and the footer.
- **Google Fonts**: For typography.
